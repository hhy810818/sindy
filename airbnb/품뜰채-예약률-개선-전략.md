
## 3. 진짜 문제 — 3단 깔때기로 보기

### (A) 노출 — 후기 10개가 발목을 잡고 있다

광진구 상위 노출 숙소들의 후기 수:

```
141 · 122 · 86 · 85 · 81 · 77 · 72 · 69 · 68 · 67 · 66 · 54 · 53 · 50 · 47 · 46 · 41 · 39 · 36 · 30 · 22
                                            ↑ 중간값 약 60개
품뜰채: 10개
```

에어비앤비 검색 랭킹은 **후기 수와 최근 예약 속도(booking velocity)** 를 강하게 반영한다. 후기 10개는 구조적으로 뒤 페이지로 밀린다. **가격을 아무리 내려도 보이지 않으면 소용이 없다.**

지금 필요한 건 "가격 인하"가 아니라 **"예약 회전수 확보 캠페인"** 이다. (→ 5장)

### (B) 클릭 — 제목과 커버 사진

#### 현재 제목

```
[서울]품뜰채 : 마당을 품을 집#안전#지하철#잠실#성수#서울숲#강남편리#어린이대공원근처
```

**문제 4가지**

1. **오타.** "마당을 **품을** 집" → "품**은**". 설명 본문에는 "품은"으로 제대로 적혀 있고 **제목만 틀렸다.** 리스팅 이름의 오타는 신뢰도를 즉시 깎는다.
2. **해시태그 8개가 전부 경쟁 열세 키워드다.** 잠실(지하철 15분), 성수(택시 10분), 강남(28분), 서울숲, 지하철(도보 12분). 이 키워드로 검색한 게스트에게 노출되면 옆에 "구의역 도보 3분", "건대역 도보 2분"이 뜬다. **이길 수 없는 싸움을 스스로 골라서 하고 있다.**
3. **유일한 차별점인 "마당"이 묻혀 있다.** 광진구 530곳 중 마당 있는 단독채는 손에 꼽는다. 상위 경쟁자들은 전부 "2026리모델링 / 미드센추리모던 / 3룸 8인 / 무료주차" — 같은 얼굴이다. 품뜰채만 다른 카테고리인데 **같은 얼굴로 위장하고 있다.**
4. **모바일에서 제목은 약 35자에서 잘린다.** 실제로 보이는 건 `[서울]품뜰채 : 마당을 품을 집#안전#지하철#잠…` 까지. 뒤 태그는 아무도 못 본다.

#### 제안 제목 (2주씩 A/B 테스트)

| 안 | 제목 | 겨냥 |
|---|---|---|
| **A** | `마당 있는 서울 단독채｜어린이대공원 도보 12분｜아이랑 가족여행·5인` | 유아 동반 가족 |
| **B** | `도심 속 마당이 있는 집, 품뜰채｜성수·서울숲 근처 한국식 단독주택 5인` | 감성·휴식 |
| **C** | `Korean House with Private Garden｜마당 있는 단독채｜Seongsu·Airport Bus 12min` | 외국인 |

**원칙: 앞 20자 안에 "마당 + 단독채"를 넣는다. 역 도보 분수는 어차피 못 이기므로 앞에 두지 않는다.**

#### 커버 사진

현재 커버 파일이 **PNG**(`75420401-….png`)다. 에어비앤비 커버가 PNG인 경우는 대개 텍스트나 로고를 얹은 편집 이미지다. 검색 결과 썸네일에서 실사 대비 클릭률이 떨어지고 "광고 같다"는 인상을 준다.

**교체안**

| 순서 | 사진 |
|---|---|
| 1 (커버) | **초록 마당 + 집 외관이 한 프레임에 들어간 실사 가로 사진.** 낮 자연광, 텍스트 없음 |
| 2 | 침실 1 (퀸베드, 정돈된 침구) |
| 3 | 거실 + 주방 (분리된 구조가 보이게) |
| 4 | 마당 브런치 세팅 |

후기 언급 태그를 보면 **청결 7회**로 압도적인 반면 **디자인 2 · 상태 2 · 수면 퀄리티 2**로 낮다. 사진도 "감성"이 아니라 **"깨끗하고 정갈함 + 초록 마당"** 을 파는 방향이 정답이다. 무리하게 감성 숙소를 흉내 낼 필요가 없다.

### (C) 전환 — 여기가 가장 큰 손실 구간이다

설명 본문을 예약을 고민하는 게스트의 눈으로 읽으면 이런 순서다.

- 얼리체크인/레이트체크아웃 **시간당 1만원 청구**
- 2인 예약 시 **침실 1개만 오픈**
- 세탁기·건조기 **3박 이상만** 사용 가능
- 주차: "골목이 좁아 **많이 불편**하실 수 있습니다"
- 욕실: "**환풍기가 따로 있지 않습니다** … **곰팡이**가 생기지 않습니다"
- "**벌레**가 발생할 수 있습니다"
- 금지·벌금 조항 15개 이상 — 실내흡연 **벌금 20만원**, 침대 오염 **세탁비 5만원**, 소음 민원 시 **퇴실(환불X)**, 인원 초과 **퇴실(환불X)**, 냄새나는 음식(고기·생선) **취사 불가**, 시설물 훼손 **배상금**, 과도한 전기 사용 **요금 부과**, 화재 시 **손해배상 청구**, 변기 막힘 **수리비 청구** …

**"환불X"가 3번, "벌금/배상/청구"가 7번 등장한다.**

규칙 자체는 전부 정당하고 필요하다. 단독주택 + 주택가라는 조건에서 나온 실전 경험일 것이다. 문제는 **위치와 비중과 어조**다. 예약을 망설이는 게스트가 마지막으로 읽는 텍스트가 벌금표라면 상당수는 뒤로 가기를 누른다. 특히 **공항버스 도보 12분이라는 큰 자산**을 가진 숙소인데, 외국인 게스트에게는 이 문장들이 훨씬 위협적으로 읽힌다.

#### 같은 화면에서 경쟁하는 숙소들의 설명은 이렇다

| 숙소 | 설명 앞부분 |
|---|---|
| 더쉼 (후기 141) | 짐 보관 **무료**, 얼리체크인 **유동적 적용**, 맛집 리스트 제공, 관광지 추천, **추가금 없이 6인**, 7박 5% / 28박 8% 할인 |

**경쟁자는 혜택 목록, 품뜰채는 금지 목록.** 내용의 질이 아니라 순서의 문제다.

#### 설명 재구성안

1. **앞 5줄 (실제로 읽히는 부분)** — 마당 이야기 + 이 집이 좋은 이유 + **혜택 3개**
2. **중간** — 공간·편의시설. 지금 내용 그대로 두면 된다. 매우 상세하고, 이게 **정확도 5.0**의 원천이다
3. **규칙은 "숙소 이용규칙(House Rules)" 필드로 이동.** 에어비앤비에는 이용규칙 전용 섹션이 있고 게스트는 예약 직전 동의 절차에서 다시 본다. **설명 본문에서 벌금표를 빼도 효력은 그대로다.**
4. 본문에 남길 규칙은 **3개만, 이유와 함께 부드럽게** — 금연 / 밤 9시 이후 마당 정숙(이웃 배려) / 반려동물 불가

## 4. 지금 안 쓰고 있는 3개의 큰 자산

### (i) 어린이대공원 도보 12분 + 마당 + 방 2개 = **유아 동반 가족 숙소**

후기에 이미 *"처음으로 아기를 데리고 남편이랑 같이 서울을 방문"* 사례가 있고 5점을 받았다.

광진구에서 "가족 여행에 적합한 숙소"로 분류된 곳은 **410곳**이지만 대부분 역세권 빌라다. **마당 있는 단독채 + 어린이대공원 도보권 + 신발 벗는 한국식 바닥**은 아기·유아 동반 가족에게 경쟁자가 거의 없는 조합이다.

> **투자 대비 효과가 가장 큰 액션**
> 아기 침대(또는 범퍼 매트) · 아기 식탁의자 · 유아 식기 · 젖병 소독기 **4종, 총 30~40만원.**
> 에어비앤비 편의시설의 **"아기 침대", "높은 의자" 필터**에 걸리기 시작한다.
> 이건 **가격이 아니라 필터로 검색 결과에 들어가는** 방법이다.
> 마당 인조잔디는 "유아에게 안전하다"는 셀링포인트로 바꿔 쓸 수 있다.

### (ii) 공항버스 6013 도보 12분 + 영어 가능 + 배달앱 QR + 실증특례 합법 숙소 = **외국인 게스트**

6013번은 김포·인천공항 노선이다. 캐리어 끌고 12분은 애매하지만 **"공항버스 정류장에서 택시 기본요금"** 으로 프레이밍하면 강력하다. 외국인 후기(Siyu)가 이미 5점이다.

- 설명 **영문 병기** — 지금은 한국어 위주에 영어가 파편적으로만 섞여 있다
- 제목에 `Korean House with Garden` 한 줄
- **LP 플레이어 · 마당 · 신발 벗는 한국 가정집** 은 외국인에게 체험 가치가 크다. 이게 진짜 차별점이다
- 단, "냄새나는 음식 취사 불가"는 내·외국인 모두에게 감점이다 (→ 3-C 표 참고)

### (iii) 7박 이상 전 객실 오픈 정책 = **장박**

정책은 이미 있는데 **리스팅 어디에도 장박 할인율이 표시되지 않는다.**

건국대·세종대가 도보/택시권이고, 광진구는 어학연수·교환학생·출장 수요가 크다. 장박은 청소 부담이 적고 공실을 메우는 가장 좋은 도구다.

- **주간 10% / 월 20~25%** 할인 설정
- 제목·설명에 **"한달살기 환영"**
- 에어비앤비 **"장기 숙박" 카테고리**(별도 검색면)에 진입한다

## 5. 실행 순서

### 즉시 — 오늘, 30분, 비용 0원

1. **제목 오타 수정** ("품을" → "품은") **+ 제목 전면 교체** (마당·단독채를 앞 20자에)
2. **커버 사진을 마당+외관 실사로 교체** (PNG → 실사)
3. **설명 구조 재배치** — 혜택 위로, 벌금표는 이용규칙 필드로 이동
4. **2인 예약 시 침실 2개 오픈**으로 정책 변경
5. **얼리체크인 · 짐보관 무료 명시**

### 1주 내 — 비용 30~40만원

6. **유아 용품 4종 구비 → 편의시설 체크 → "가족 여행" 필터 진입**
7. **주간 10% / 월 20% 장박 할인 설정**
8. **사진 재촬영** — 낮 자연광, 마당 4컷 이상 (브런치 세팅 / 초록 / 저녁 조명)

### 2~8주 — 후기 볼륨 확보 캠페인 (여기가 핵심)

9. **가격은 내리지 말고, "빈 날짜"만 공격적으로 채운다**
   - 정가 ₩119,788 → **₩95,000** 현실화 (상시 33% 할인 구조 해체)
   - 평일 ₩69,000 / 주말 ₩89,000 **요일 차등**
   - **3일 전 미예약 날짜 자동 -25%**
   - **최소 숙박일수 1박 유지** (2박 이상으로 묶으면 빈 하루가 계속 남는다)
10. **후기 요청 루틴** — 체크아웃 당일 감사 메시지 + 3일 뒤 후기 요청.
    응답률 100% · 1시간 이내 응답이라는 강점이 있으니 후기 전환은 잘 나올 것이다.
11. **목표: 10월 말까지 후기 25~30개.** 이 구간을 넘기면 검색 노출이 계단식으로 올라간다. **그때 가격을 다시 올린다.**

### 분기 목표

12. **슈퍼호스트 획득**
    평점 5.0 ✅ / 응답률 100% ✅ / 취소율 0% ✅ — **부족한 건 숙박 횟수(연 10회 이상) 하나뿐이다.**
    위 캠페인으로 예약 수만 채우면 다음 평가일(1/1 · 4/1 · 7/1 · 10/1)에 자동으로 받는다.
    **게스트 선호 + 슈퍼호스트 배지 두 개가 검색 결과에 함께 뜨면 클릭률이 확 달라진다.**

## 6. 하지 말아야 할 것

- **추가 가격 인하** — 이미 33% 할인 중이다. 더 내리면 ₩49,648짜리 7인 역세권 숙소와 정면 승부가 되고 원가 구조상 진다. 그리고 한번 내린 가격은 후기의 "가격 대비 만족도"에 기대치를 고정시켜 되돌리기 어렵다.

- **역세권 키워드 경쟁** — 도보 12분으로 도보 1~3분과 싸우지 않는다.
